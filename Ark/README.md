# Ark

Starter workspace for ARK modding projects.

## Pre-setup structure

- `mods/` - individual ARK mod projects
- `notes/` - design notes, migration notes, and research
- `templates/mod-template.md` - starter checklist for a new mod
- `wiki.md` - primary wiki references
- `links.md` - key modding and API links

## Notes

This folder is aimed at ARK DevKit workflows. The current official docs are for ARK: Survival Ascended, while legacy ASE references are still useful for older projects.
