# Skyrim

Starter workspace for Skyrim modding projects.

## Pre-setup structure

- `mods/` - individual Skyrim mod projects
- `notes/` - design notes, compatibility notes, and research
- `templates/mod-template.md` - starter checklist for a new mod
- `wiki.md` - primary wiki references
- `links.md` - key modding and API links

## Notes

This folder is intended for Creation Kit, Papyrus, SKSE, and xEdit-based Skyrim work.
