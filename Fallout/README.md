# Fallout

Starter workspace for Fallout modding projects.

## Pre-setup structure

- `mods/` - individual Fallout mod projects
- `notes/` - design notes, load order notes, and research
- `templates/mod-template.md` - starter checklist for a new mod
- `wiki.md` - primary wiki references
- `links.md` - key modding and API links

## Notes

This folder is aimed at Bethesda-era Fallout modding, especially Fallout 4 and Fallout: New Vegas tooling such as the Creation Kit/GECK, script extenders, and xEdit.
