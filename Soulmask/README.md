# Soulmask

Starter workspace for Soulmask modding and server customization.

## Pre-setup structure

- `mods/` - individual mod or server package work
- `notes/` - gameplay, server, and mod research
- `templates/mod-template.md` - starter checklist for a new mod
- `wiki.md` - primary wiki references
- `links.md` - key modding and API links

## Notes

Public documentation for Soulmask currently centers on the official Steam Workshop/Modkit entry points plus community-maintained technical guides for server and mod workflows.
